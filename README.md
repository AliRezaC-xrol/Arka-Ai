# Arka

> محیط چت و تولید تصویر با هوش مصنوعی — هر پروایدری که بخواهی وصل کن.

**وضعیت: فاز ۰ تکمیل شد** (اسکلت + تم + هیرو + ورود نمایشی + شِل چت موک). نقشه‌ی کامل در [`docs/SPEC.md`](docs/SPEC.md) و گزارش فاز در [`docs/PHASE_0_REPORT.md`](docs/PHASE_0_REPORT.md).

## استک

- Next.js 15 (App Router) + TypeScript + React 19
- Tailwind CSS v4 + کامپوننت‌های shadcn/ui-style
- فونت فارسی Vazirmatn (self-host) + استک سیستمی اپل برای لاتین
- تم مشکی یکتا — بدون سایه، فقط hairline border
- Prisma (اسکیما اسکیفت شده؛ از فاز ۱ به PostgreSQL وصل می‌شود)

## اجرا

```bash
pnpm install
pnpm dev        # http://localhost:3000
```

اسکریپت‌ها: `pnpm build` · `pnpm start` · `pnpm lint` · `pnpm typecheck`

## مسیرها

| مسیر | توضیح |
|---|---|
| `/` | هیرو و لندینگ با انیمیشن اسکرول |
| `/login` | ورود نمایشی (گوگل / ایمیل + OTP شش‌باکسی) — بدون بک‌اند |
| `/chat` | شِل چت موک با باکس اسپاتلایت و انتخاب‌گر مدل |
