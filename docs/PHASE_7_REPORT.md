## ۱. اهداف و دستاوردهای کلیدی فاز ۷

در این فاز، زیرساخت پیام‌رسانی متمرکز ادمین، اعلان‌های همگانی و خصوصی، ردیابی بلادرنگ وضعیت خوانده‌شدن و حذف چندسطحی پیاده‌سازی شد:

1. **صفحه اختصاصی «پیام‌رسانی» در سایدبار ادمین (`/c-xroladi1n`):**
   - **فرم ارسال پیام جدید:**
     - فیلد عنوان اختیاری و متن پیام الزامی.
     - انتخاب گیرنده به صورت رادیوباتن:
       - «همه کاربران (همگانی)»: ارسال خودکار به تمام کاربران ثبت‌شده در سیستم.
       - «یک کاربر خاص»: جستجوی زنده در میان کاربران (با نام یا ایمیل) و انتخاب کاربر مقصد.
   - **لیست «پیام‌های ارسال‌شده»:**
     - نمایش تاریخ و ساعت دقیق ارسال، عنوان و متن پیام.
     - نوع گیرنده (همه کاربران به همراه تعداد یا کاربر خاص).
     - نمایش وضعیت خوانده‌شدن به صورت آمار عددی و درصدی (مثلاً «۱۲ از ۵۰ نفر خوانده‌اند (۲۴٪)») همراه با نوار پیشرفت بصری گرادیانتی.

2. **سیستم حذف چندسطحی (Multi-tier Deletion):**
   - **حذف برای همه گیرندگان:** حذف پیام اصلی که به صورت آبشاری پیام را از صندوق ورودی تمام کاربران و پنل مدیریت پاک می‌کند.
   - **حذف فقط برای یک کاربر خاص:** در پیام‌های همگانی، ادمین می‌تواند از طریق مودال وضعیت گیرندگان، پیام را فقط از صندوق یک کاربر مشخص حذف کند (`isDeleted: true`)، در حالی که سایر کاربران کماکان پیام را در نوتیفیکیشن‌های خود می‌بینند.

3. **مودال جزئیات و وضعیت گیرندگان (Recipients Breakdown):**
   - لیست کامل کلیه گیرندگان پیام با نام، ایمیل، وضعیت خوانده‌شدن (`خوانده‌شده` / `خوانده‌نشده`) و تاریخ و ساعت دقیق مطالعه پیام.
   - دکمه اقدام اختصاصی «حذف فقط برای این کاربر».

4. **سیستم اعلان‌ها و زنگوله نوتیفیکیشن کاربر (`/chat`):**
   - کامپوننت `NotificationsMenu` در هدر صفحه چت در کنار منوی کاربر.
   - نشانگر پالس‌دار تعداد پیام‌های خوانده‌نشده (`badge count`).
   - منوی بازشونده با لیست پیام‌ها، تاریخ ارسال و وضعیت.
   - **ثبت وضعیت خوانده‌شده در لحظه:** با کلیک کاربر روی پیام، وضعیت آن فوراً به «خوانده‌شده» تبدیل شده و در پنل ادمین نیز بلادرنگ درصد خوانده‌شدن افزایش می‌یابد.
   - دکمه «خواندن همه» جهت علامت‌گذاری یک‌باره پیام‌ها.

5. **امنیت و مخفی‌سازی مسیرها (Route Hiding):**
   - اندپوینت‌های `/api/admin/broadcasts/*` برای کاربران احرازهویت‌نشده کد `404 Not Found` بازمی‌گردانند.
   - اندپوینت `/api/notifications` در سطح میدلور و روت هندلر برای کاربران لاگین‌نکرده محافظت‌شده است.

## ۲. مدل‌های پایگاه‌داده (Prisma Schema)

مدل‌های زیر در PostgreSQL ایجاد شدند:

```prisma
model AdminMessage {
  id        String   @id @default(uuid())
  title     String?
  content   String   @db.Text
  sentAt    DateTime @default(now()) @map("sent_at")
  sentToAll Boolean  @default(false) @map("sent_to_all")
  createdAt DateTime @default(now()) @map("created_at")
  updatedAt DateTime @updatedAt @map("updated_at")

  recipients MessageRecipient[]

  @@map("admin_messages")
}

model MessageRecipient {
  id             String    @id @default(uuid())
  adminMessageId String    @map("admin_message_id")
  userId         String    @map("user_id")
  isRead         Boolean   @default(false) @map("is_read")
  readAt         DateTime? @map("read_at")
  isDeleted      Boolean   @default(false) @map("is_deleted")
  createdAt      DateTime  @default(now()) @map("created_at")
  updatedAt      DateTime  @updatedAt @map("updated_at")

  adminMessage AdminMessage @relation(fields: [adminMessageId], references: [id], onDelete: Cascade)
  user         User         @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@unique([adminMessageId, userId])
  @@index([userId, isDeleted, isRead])
  @@index([adminMessageId])
  @@map("message_recipients")
}
```

## ۳. اندپوینت‌های ایجادشده در فاز ۷

1. `GET /api/admin/broadcasts`: لیست پیام‌های ارسال‌شده با تجمیع آمار و اسامی گیرندگان (محافظت با سشن ادمین و ۴۰۴).
2. `POST /api/admin/broadcasts`: ارسال پیام همگانی به همه کاربران یا یک کاربر خاص به همراه ایجاد رکوردهای `MessageRecipient`.
3. `DELETE /api/admin/broadcasts/[id]`: حذف کامل پیام و پاک‌سازی از صندوق تمام گیرندگان.
4. `DELETE /api/admin/broadcasts/[id]/recipients/[userId]`: حذف اختصاصی پیام تنها از حساب یک کاربر مشخص.
5. `GET /api/notifications`: واکشی اعلان‌های فعال کاربر جاری به همراه تعداد خوانده‌نشده‌ها.
6. `POST /api/notifications/[id]/read`: علامت‌گذاری پیام به عنوان خوانده‌شده به همراه ثبت زمان دقیق.
7. `POST /api/notifications/read-all`: علامت‌گذاری دسته‌جمعی تمامی پیام‌ها به عنوان خوانده‌شده.
