## ۱. خلاصه‌ی تغییرات و فایل‌ها

### فایل‌های جدید ایجادشده:
1. `src/lib/crypto.ts`: توابع رمزنگاری و رمزگشایی دوسویه کلیدهای API با الگوریتم **AES-256-GCM** (همراه با IV تصادفی ۱۲ بایتی و Authentication Tag شانزده بایتی)، به همراه تابع `maskApiKey` جهت ماسک کردن کلید در خروجی‌های فرانت‌اند (مانند `sk-...ab12`).
2. `src/lib/provider-tester.ts`: ماژول تست زنده و اعتبارسنجی اتصال به پروایدرهای OpenAI، Anthropic، Google Gemini و پروایدرهای سفارشی با مدیریت Timeout، بررسی کدهای وضعیت و بازگرداندن پیام‌های خطای فارسی دقیق.
3. `src/app/api/user-providers/route.ts`: اندپوینت دریافت لیست پروایدرهای شخصی کاربر (`GET`) و افزودن پروایدر جدید با رمزنگاری کلید و تست اتصال اختیاری (`POST`).
4. `src/app/api/user-providers/[id]/route.ts`: اندپوینت دریافت جزئیات پروایدر (`GET`)، ویرایش اطلاعات و به‌روزرسانی کلید (`PATCH`) و حذف پروایدر (`DELETE`) با بررسی دقیق احراز هویت و ایزولاسیون کاربری.
5. `src/app/api/user-providers/[id]/test/route.ts`: اندپوینت اختصاصی تست مجدد اتصال پروایدر (رمزگشایی کلید در سرور و ارسال درخواست اعتبارسنجی سبک).
6. `src/app/settings/providers/page.tsx`: صفحه کامل تنظیمات پروایدرهای شخصی کاربر با طراحی تیره مینیمال، شامل فرم مودال افزودن پروایدر، نمایش وضعیت زنده (متصل شد/خطا در اتصال/تست‌نشده)، دکمه تست مجدد اتصال، و حذف پروایدر.
7. `src/app/settings/page.tsx`: ریدایرکت خودکار به بخش `/settings/providers`.
8. `scripts/test-phase3.ts`: اسکریپت تست خودکار کلیه سناریوهای فاز ۳.

### فایل‌های ویرایش‌شده:
1. `prisma/schema.prisma`: اضافه شدن مدل `UserProvider` با جدول `user_providers` در PostgreSQL، شامل فیلدهای `id`, `userId`, `name`, `providerType`, `baseUrl`, `encryptedApiKey`, `keyMask`, `models`, `status`, `lastTestedAt`, `lastTestMessage`, `createdAt`, `updatedAt` و رفرنس به `users`.
2. `src/components/model-picker.tsx`: ارتقای کامپوننت انتخاب مدل جهت پشتیبانی از پروایدرهای شخصی کاربر، نمایش برچسب زرد/کهربایی «پروایدر شخصی» و آیکون کلید 🔑 در کنار مدل‌های متصل کاربر.
3. `src/components/user-menu.tsx`: فعال‌سازی لینک «تنظیمات و پروایدرها» به مسیر `/settings/providers` و حذف نشان «به‌زودی».
4. `src/app/chat/page.tsx`: دریافت زنده پروایدرهای متصل کاربر از سرور، افزودن پویای آن‌ها به `ModelPicker`، و ارسال شناسه `userProviderId` هنگام چت با مدل‌های شخصی.
5. `src/app/api/chat/route.ts`: پشتیبانی از پردازش و استریم پیام‌ها از طریق پروایدر شخصی کاربر با رمزگشایی امن کلید در سرور.
6. `src/middleware.ts`: اضافه شدن مسیرهای `/settings` و `/api/user-providers` به مسیرهای محافظت‌شده (Protected Routes) جهت جلوگیری از دسترسی کاربران غیرمجاز.

## ۲. تطبیق کامل با الزامات فاز ۳

### ۱. صفحه تنظیمات پروایدرها (`/settings/providers`)
- صفحه تحت نظارت Middleware قرار دارد و دسترسی به آن نیازمند لاگین معتبر است.
- فرم ایجاد پروایدر شامل فیلدهای:
  - نام نمایشی پروایدر (مانند «OpenAI شخصی من»)
  - انتخاب نوع پروایدر (`openai`, `anthropic`, `google`, `custom`)
  - آدرس Base URL (برای مدل‌های سفارشی مانند DeepSeek یا سرورهای سازگار با OpenAI)
  - کلید API با قابلیت مشاهده/مخفی‌سازی رمز
  - چک‌باکس تست فوری اتصال به هنگام ثبت
- لیست پروایدرها تنها پروایدرهای متعلق به همان کاربر لاگین‌شده را نمایش می‌دهد.

### ۲. تست اتصال (Connection Test)
- دکمه تست اتصال، درخواست سبک به API پروایدر ارسال کرده و وضعیت را بلافاصله نشان می‌دهد:
  - **متصل شد ✓** (بج سبز)
  - **خطا در اتصال ✗** (بج قرمز با توضیح دقیق خطا اعم از 401 Unauthorized، آدرس اشتباه یا Timeout)
  - **تست‌نشده** (بج خنثی)
- تاریخچه آخرین تست و متن پیام در دیتابیس ثبت شده و به کاربر نشان داده می‌شود.
- امکان اجرای تست مجدد در هر زمان تنها با یک کلیک فراهم است.

### ۳. امنیت و رمزنگاری کلیدهای API
- کلیدهای API **هرگز به صورت متن خام (Plain Text) در دیتابیس ذخیره نمی‌شوند.**
- با استفاده از استاندارد قوی **AES-256-GCM** و کلید ۳۲ بایتی سمت سرور رمزنگاری می‌شوند.
- در رابط کاربری و پاسخ‌های API فقط کلید ماسک‌شده (مانند `sk-...ab12`) نمایش داده می‌شود و کلید اصلی هرگز پس از ذخیره اولیه به مرورگر فرستاده نمی‌شود.

### ۴. استفاده از پروایدر شخصی در محیط چت
- پروایدرهای متصل کاربر به صورت خودکار به منوی انتخاب مدل (`ModelPicker`) اضافه می‌شوند.
- مدل‌های شخصی با آیکون کلید 🔑 و برچسب «پروایدر شخصی» از مدل‌های پیش‌فرض متمایز هستند.
- با انتخاب مدل شخصی، درخواست‌ها مستقیماً با احراز هویت و کلید اختصاصی کاربر ارسال و استریم می‌شوند.

### ۵. مدیریت و حذف پروایدر
- امکان حذف پروایدر شخصی با تایید کاربر وجود دارد؛ به محض حذف، پروایدر از دیتابیس و همچنین از منوی انتخاب مدل در صفحه چت حذف می‌شود.
